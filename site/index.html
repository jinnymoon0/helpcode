helpcode Downloads

LeetCode hint helper extension (hints only, no full answers).

Download for Chrome Download for Safari

If Safari download is unavailable, use the Chrome download and follow Safari conversion instructions below.

Install in Chrome

  1. Download helpcode-chrome.zip and unzip it.
  2. Open chrome://extensions.
  3. Enable Developer mode.
  4. Click Load unpacked and select the unzipped folder.

Install in Safari (macOS)

  1. Download helpcode-safari.zip and unzip it.
  2. Open the included .xcodeproj in Xcode and set your signing Team.
  3. Run the macOS app target once from Xcode (Cmd + R).
  4. In Safari, open Settings -> Extensions and enable helpcode Extension.
